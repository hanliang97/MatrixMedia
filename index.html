矩媒 MatrixMedia自媒体 · 矩阵 · 批量

多平台视频矩阵发布与批量分发工具（Electron + CLI）。一次准备内容，批量分发到抖音、快手、小红书、视频号、B站等账号矩阵；并提供 CLI、HTTP API 与 MCP，方便脚本与 AI 编排。

快速开始
GitHub 下载
查看仓库

GUI 矩阵发布

图形界面管理多账号，批量上传本地视频，适合日常矩阵运营。

CLI 自动化

登录（抖音 / 视频号）、发布、账号状态与发布历史查询，便于脚本与无人值守。

HTTP API

GUI 运行时本机 30088 端口触发发布，供其它程序与工作流调用。

MCP / AI 编排

通过 MCP Server 或外部命令对接 OpenClaw、Cursor、Dify、n8n 等智能体框架。

支持平台 ​

抖音 · 快手 · 百家号 · 哔哩哔哩 · 头条号 · 视频号 · 小红书 · 番茄视频
